## 安装、卸载与重载

1. 当前进程对应的官方 CLI 安装包；运行中用 profile 用户补丁加载。
2. 首次发现 rc.2 仅新增 bundle 不进入当前进程的实时合成，改为单一受管补丁，防止下次启动重复服务。
3. 验证过程还发现，同一个 Loader id 只改模块名会留下旧客户端来源缓存；早期位于插件包内部的临时探针也被识别成该客户端包。已清理本次遗留来源，将观察器移至包外。最终安装器使用带版本的 Loader id，使旧条目移除、新条目重新创建。
4. 最终卸载时：TG 的 Remote 注册和 `dsh-tg` 客户端模块均消失，其他模块保留；存储域正常释放。
5. 直接从旧版切换新版条目时，发现宿主先创建新条目、再删除旧条目，游戏存储仍被旧实例占用，更新未实际完成。0.1.6 安装器改为先撤销旧条目，通过临时 Cordis 助手确认旧服务消失且存储域可打开并关闭，再加载新版；助手立即从配置移除。真实更新取得 `{ok:true}` 的存储释放回执。
6. 最终重新安装时：确认 Loader 使用 `?tg=0.1.6`，服务和客户端模块恢复，客户端实际来源是 profile 安装目录。两局测试世界的 SHA-256 与卸载前完全一致，照片结算、时间和收据保留。

## 本次发现并修复的问题

- Host 标准装饰器不能由 Node 22 直接运行：构建增加显式转换和语法检查。
- 侧栏存在但打开空白：修正 `remote.tg` 依赖注入和官方 `RemoteResult` 解包。用户随后确认“出现了”。
- 真实模型买东西时把商品编号写进人物目标字段，耗尽阶段预算：补充字段示例和可操作的校验错误；原失败没有扣钱或推进时间，0.1.4 真实模型重测购物通过。
- 存储探针重复打开域与重载缓存问题：按上文分别修正清理时机及安装方式，未修改或升级宿主。

## 浏览器验收及剩余项

浏览器工具访问本机返回 `ERR_BLOCKED_BY_CLIENT`，当前没有可控制的已登录 Chrome。未登录请求仍为 `401`。因此保留正常认证，由用户在现有浏览器确认界面。

- 已确认：侧栏出现“文字游戏”；空白修复后出现“浮城纪事”与开局/继续旅程界面。
- 待用户反馈：新开局后输入“等待5分钟”，处理结束点击一个生成选项，再刷新确认进度保留、没有错误。
- 尚未实测：浏览器多标签竞争、断线重连、卸载前后侧栏的视觉变化、所有管理页的逐项点击与窄屏布局。相关核心规则和 Host 生命周期检查已有结果，但不能替代这些界面验收。
