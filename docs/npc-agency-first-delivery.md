### NPC 可调用的工具

- `npc_offer_reward`：有限金钱、已登记物品、消耗空白纸生成无属性/售价的文字纪念品。
- `npc_invite_player`：本人登记子区域内、未来有效时间窗的邀请。
- `npc_make_promise`：有资源支持的礼物承诺或可验证的会面承诺。
- `npc_set_intention`：记录、替换、完成或取消私下意图；按再次相遇、游戏时间或提议结果变为可重新考虑。
- `npc_update_impression`：仅引用已知事实，单回合关系变化 -5 至 +5；允许零或负变化。
- `issue_quest`：先提出任务卡片，再由玩家接受；新模型任务只允许 `npc_discretionary`，不能凭空创造固定奖励。

工具调用结果 `STAGED` 不是已执行。必须有非空最终答复，且操作 scope 与完整业务快照仍有效，才整体提交。礼物提议提交后仍未入账，玩家接受时才扣 NPC 资产并增加玩家资产。拒绝、撤回或到期释放预留；尚未到截止日的承诺不会因其中一次礼物提议过期而丢失预留或卡死。

### 状态与兼容

`$npcAgency` 保存 actors、facts、jobs、decisions、offers、promises、intentions、receipts、encounters、itemDefinitions。运行时 Promise/AbortController 不入存档。

- 身份使用 actorId，运行 NPC 换 ID 后仍能领取原礼物、恢复回应和交付已接受任务；旧姓名仅在匹配唯一时迁移，同名不同人不合并。
- 玩家话语只记为 player_statement，不能当成任务完成证明。
- 照片需实地寻找获得真实凭证，并当面移交；模型生成选项不能伪造照片进度。
- `fixed` 保留原任务奖励；`npc_discretionary` 不预设奖励；`fixed_plus_npc` 分别保存固定结算与自主回报。
- 旧数组背包兼容；生成物品以纯文本显示名称/描述，不执行宏、HTML 或脚本。
- 关系不再随每句聊天固定增加。稳定 NPC 不因关系归零被删除。
- 已提交回合、任务结算与玩家领取分别去重；重新加载页面不重复入账。
- 旧异步请求、旧 DOM 回调不能影响读档/导航后的新状态。设置页读档不再额外跳到 Start。

## 正式体验步骤

1. `start.bat`，使用支持 tools 的模型。
2. 起床 → 街道 → 公园 → **与晚晴交谈**（固定入口，不依赖模型成功生成场景）。
3. **询问遗失的照片** → 接受请求 → 结束对话。
4. **去林间小径寻找照片** → **寻找晚晴遗失的照片** → 回入口 → **前往交还照片** → **交付：晚晴遗失的合影**。
5. 等待 NPC 自主回应；提议出现后由玩家接受或拒绝。请求被打断时使用 **继续回应**，不重复交付任务。
6. 正常睡眠/休息推进到次日，回到 NPC 所在子区域。若有邀请，接受后在时间窗内手动 **赴约**。

- 接受邀请后未自动移动或推进时间；正常休息至 01:00，再进入对话并点击赴约，卡片变为 **已赴约**，按钮消失。

## 明确边界

- 真实端到端只验证了当前 OpenAI-compatible 模型；Ollama 是 fixtures 通过，未连接真实 Ollama 服务。
- 本轮真实随机样本覆盖送钱与次日邀请；拒绝礼物、纪念品、公开承诺及过期等分支以自动化验证，不冒称全部真实模型 UI 分支都走过。
- 这是功能与一致性验收，不是多模型、多初始运行的叙事质量评测。模型可能在文字里重复感谢或表达超出动作状态的修辞；程序效果仍只认已验证动作和收据。
- NPC 首批不自主移动、不离线模拟日程；邀请目的文字不生成新路线或自动执行“散步”。
- 私下意图触发后由模型重新判断并用 tool 标记完成，不用自然语言规则自动猜测“这个动作实现了哪条意图”。
- 长期事实/决策目前随存档保留，尚未实现无限时长游戏的记忆压缩或大型社会模拟。

未增加构建工具或后端依赖，未提交或推送 Git。测试临时服务在验收后停止。

## 2026-09-07 交付回应与任务状态修复

- 交付事件携带 `questId`；接受事件携带 `offerId`、`questId`、`resolution`。旧存档通过提议与 `sourceEventId` 关联，保留原始事实。
- 同任务已经结算时，未提交的接受回应标为 `superseded`。取消其运行请求，禁止旧回复和工具草稿提交，不影响其他任务、玩家消息或礼物事件。
- 进入对话时恢复 queued/retryable/遗留 running 事件；等待旧请求释放运行锁后自动开始交付回应。离开页面或读档阻止旧回调继续调度；失败不无限重试。结算回应优先于相遇事件，不自动刷完历史相遇队列。
- NPC 上下文包含真实 `questStates` 及本轮关联任务，区分“已完成交付”和“未记录具体成果”；主观评价和奖励仍由模型自主决定。提示词不等于自然语言一致性的绝对保证。
- 已验证任务行动保存 `lastAction`（行动、地点、时间），交付保留目标快照；模型发布任务不能注入此记录。旧存档不虚构选瓶结果，也不重做任务或奖励。
